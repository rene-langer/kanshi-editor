# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep feedback about the work, not
the person. Harassment, insults and discrimination aren't tolerated anywhere in the
project's spaces.

To report a problem, contact the maintainer privately, for example through
[GitHub private vulnerability reporting](https://github.com/rene-langer/kanshi-editor/security/advisories/new)
if it needs to stay confidential. Every report is reviewed and handled discreetly.
